🏗️ 1. System Architecture & Tech Stack

ControlPlane AI is an inline AI security gateway inserting a sub-15ms interception layer between users, agent frameworks, and LLM providers. It evaluates every prompt across three dimensions:

  • Performance (P): Evaluates response factuality via FacTool verification and web search.
  • Cost ($): Audits token consumption and enforces per-request budget limits.
  • Responsibility (R): Runs regex scanning, heuristic indicator scoring, PII redaction, bias detection, and prompt injection filters.

Tech Stack:

LayerTechnologyPurpose
BackendPython + FastAPI + UvicornREST API, guardrail evaluator engine, SQLite ORM
FrontendVanilla HTML/CSS/JS (ES6 Modules)SPA dashboard with hash-based routing
DatabaseSQLite (aiosqlite)Users, resources, policies, interceptions, scans, tokens
ExtensionChrome Manifest V3Network interceptor for AI platforms
TestingPytest (59 tests)Evaluators, routes, DB operations

Three-Layer Flow:

User / AI Agent  -->  Chrome Extension / SDK  -->  ControlPlane Backend (6 Evaluators)  -->  Risk Findings Dashboard

Enforcement Action Breakdown:

  • ALLOW — Clean queries, no modification.
  • MASK — PII auto-redacted before forwarding.
  • MONITOR — Flagged for audit, allowed through.
  • BLOCK — Dangerous queries immediately halted.

📦 3. Monitored Resources

A Resource represents any AI chatbot or agent endpoint under guardrail protection.

Key Fields:

  • Resource Name — Human-readable label (e.g., "Customer Support Bot")
  • Webhook ID — Botpress webhook UUID or API endpoint identifier
  • Use Case Type — Security profile: customer_support, internal_copilot, decision_support

Backend Functions:

  • create_resource(data) — Registers a new chatbot with a unique res_ ID
  • list_resources() — Returns all resources for the tenant
  • get_resource(id) — Fetches a single resource by ID
  • validate_resource(id) — Pings the webhook URL to verify reachability

🔬 8. Hallucination & Factuality Detector

Based on the FacTool framework, verifies LLM responses by extracting claims and cross-referencing against live web search evidence.

Three-Stage Pipeline:

  1. Claim Extraction — OpenAI extracts factual claims as a JSON array
  2. Evidence Retrieval — Serper API searches Google for supporting evidence
  3. Verdict Generation — OpenAI evaluates each claim, assigns factuality score (0.0–1.0)

Modes:

  • Live Mode — Requires OpenAI + Serper API keys for real-time verification
  • Fallback Mode — No keys needed, uses built-in evaluator for offline testing

🔌 9. Chrome Extension Network Shield

Intercepts prompt forms and network fetch calls on AI platforms to mask credentials and block injections before text leaves the browser.

How It Works:

  1. content.js runs on AI platform pages (ChatGPT, Claude, etc.)
  2. When user clicks Send, extension captures the prompt text
  3. Sends prompt to POST /api/v1/resources/{id}/check
  4. BLOCK → prevents submission. MASK → redacts PII before sending
  5. All results logged to Risk Findings dashboard

Extension Files:

  • manifest.json — Chrome Manifest V3 configuration
  • popup.html / popup.js — Popup UI for enrollment and connection status
  • content.js — Content script for prompt interception
  • background.js — Service worker for network monitoring

🔐 10. Security Engine & Cryptographic Integrity

ControlPlane runs 6 evaluator functions on every prompt in sequence:

#EvaluatorFileWhat It Does
1Prompt Injectioninjection.py3-layer: L1 Regex → L2 Heuristic Scoring → L3 LLM Check
2PII Scannerpii.pyDetects/redacts emails, cards, SSNs, phones, API keys
3Bias & Toxicitybias_safety.pyHate speech, profanity, discriminatory language
4Groundinggrounding.pyValidates response factuality against context
5Cost Analysiscost.pyToken usage estimation and budget enforcement
6Action Riskaction_risk.pyAgent tool calls against 4-tier risk classification

SHA-256 Hash Chain:

Current Hash = SHA-256(Previous Hash + Interception Data Payload)

Every check is cryptographically chained. If any record is deleted or modified, the next hash mismatches, instantly flagging log tampering.
