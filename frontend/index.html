📦 3. Monitored Resources & Use-Case Policies

Resources map to distinct AI chatbot instances, agent runtimes, or customer support bots. Each resource is governed by an adaptive Policy Profile:

  • Customer Support (pol_customer_support): Low latency priority, aggressive PII masking (Credit cards, SSNs), polite hedging filters.
  • Internal Copilot (pol_internal_copilot): Internal credential shielding, API key protection, token overflow limits.
  • Decision Support (pol_decision_support): High factuality enforcement, strict RAG grounding verification, AI judge edge-case triggers.
  • Autonomous Agent (pol_ai_agent): Tool call action-risk tiering (LOW/MED/HIGH/CRITICAL), compound sequence exfiltration tracking.
  • EU GDPR / US HIPAA: Regional compliance templates enforcing legal data minimization rules.

🤖 4. AI Agent Runtime & Compound Sequences

Before an autonomous agent executes a tool call, ControlPlane evaluates its danger level and action history to prevent malicious tool misuse and multi-step data exfiltration:

TierExample ToolDefault ActionBehavior
LOWsearch_web, calculateALLOWImmediate execution with sub-5ms latency
MEDIUMsend_email, post_slackMONITORExecuted and recorded to audit telemetry
HIGHdelete_file, modify_userCONFIRM_REQUIREDPaused until approved in Human Review Queue
CRITICALtransfer_money, drop_dbBLOCKImmediate hard halt, security alert logged

Compound Exfiltration Chain Detection:

If an agent's prior history includes sensitive data access (e.g. read_file, query_db) and the current action is external transmission (e.g. send_email, webhook_post), ControlPlane escalates the action to CONFIRM_REQUIRED to prevent automated data exfiltration.

👥 5. Human-in-the-Loop (HITL) Review Queue

When prompt checks or agent tool calls produce CONFIRM_REQUIRED or borderline risk, they are queued for security review.

Available Operator Actions:

  • ✓ Approve: Confirms the prompt/tool call is benign and authorizes continuation.
  • ✕ Reject & Block: Confirms the threat and enforces hard blocking.
  • ⚡ Override: Grants an authorized executive business exception with mandatory audit notes.
  • 🎯 False Positive & Auto-Tune: Marks the finding as a false detection, automatically recalibrating and loosening policy strictness thresholds.

📈 6. Cumulative Multi-Turn Session Risk

Attackers often bypass single-prompt guardrails through "salami slicing" (asking small, seemingly benign sub-questions that collectively reconstruct an exploit). ControlPlane tracks cumulative session risk over time:

$$\text{Score}_{t} = (\alpha \times \text{Score}_{t-1}) + (\text{Turn Risk} \times 0.5)$$
Where decay constant $\alpha = 0.85$. If cumulative session risk exceeds threshold (0.65), actions escalate from MONITOR to CONFIRM_REQUIRED or BLOCK.

⚖️ 7. AI-as-a-Judge Tiered Fallback

To balance speed and nuanced semantic understanding, ControlPlane utilizes a 2-tier architecture:

  • Tier 1 (Fast Deterministic Path, < 15ms): Evaluates 95%+ of traffic using regex, token bounds, and heuristic patterns. Clear ALLOW or BLOCK decisions return immediately.
  • Tier 2 (AI Judge Fallback): Triggered only for borderline risk scores ($0.40 \le \text{Risk} \le 0.70$) or complex decision support prompts. Invokes an LLM judge to provide nuanced reasoning and final verdict.

🔬 8. Evidence-Backed RAG Grounding & Factuality

Verifies whether LLM chatbot responses are grounded in provided enterprise knowledge context or hallucinated:

  1. Claim Extraction: Parses complex model responses into atomic factual statements.
  2. Context-Faithfulness Check: Cross-references claims against provided RAG context documents.
  3. Web Search Verification: Falls back to live Google Search (via Serper API) when external facts must be validated.

  • PDF Export: Generates branded PDF compliance audit reports for executive stakeholders.

🔌 12. Chrome Extension Network Shield

Client-side prompt interception for ChatGPT, Claude, Gemini, DeepSeek, and custom webchats:

  1. Load unpacked directory: frontend/extension/ in chrome://extensions/.
  2. Auto-enroll using an active token from the Enrollment Tokens dashboard tab.
  3. Prompts are checked and sanitized transparently before departing the user's browser.

🔐 13. Evaluators & Cryptographic SHA-256 Hash Chain

Every check generates a tamper-evident audit record linked via SHA-256 hash chaining: 

Current Hash = SHA-256(Previous Hash + Interception Data Payload)

If any past audit log row is modified or deleted, the subsequent hash fails verification, immediately exposing log tampering.
