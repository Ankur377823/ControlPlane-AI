📚 ControlPlane AI Enterprise Security Guide

Integrate and configure the real-time guardrail shield, LegionForge Guardian 7-check engine, and cryptographic log chains.

🔍 1. System Architecture & Capabilities

ControlPlane AI acts as an inline security broker inserting a sub-15ms interception layer between users, agent frameworks, and LLM providers. It runs evaluations across three dimensions:

  • Performance (P): Evaluates response factuality and grounding against real-time search evidence (FacTool verification).
  • Cost ($): Audits token metrics and enforces budgets to block expensive inputs or runaway loops.
  • Responsibility (R): Runs deterministic regex scanning, PII redaction, and prompt injection filters before the prompt hits the LLM.

Policy Enforcement Tiers:

Tier Effect Ideal Use Case
ALLOW Passes cleanly with no changes. Safe daily chatbot interactions.
MONITOR Passes while logging finding to DB. Internal non-critical copilots.
MASK Redacts emails/keys before sending. Customer support chatbots.
BLOCK Immediately halts query execution. Critical actions (database wipe).

🤖 2. LegionForge Guardian 7-Check Engine

We integrate a zero-LLM deterministic check shield running before agent tool execution: 

Check 0: Task Token ACL ────── Validates JWT/scoped token tool authorizations
Check 1: Tool Registry ──────── Verifies tool is active and not revoked
Check 2: Capability Boundary ── Blocks forbidden command keywords (e.g. spawn_agent_direct)
Check 3: Pattern Detection ──── Scans parameters against 9 regex injection/SSRF threat families
Check 4: Sequence Contracts ── Ensures state machine transitions (playbooks) match contracts
Check 5: Hash Integrity ─────── Tamper detection via SHA-256 schema hash validation
Check 6: Adaptive Rules ─────── Tenant hot-reloaded blocklists from database

Integrating in Python (LangGraph, AutoGen, CrewAI):

import httpx

async def check_agent_tool(tool_name, tool_args, session_id):
    async with httpx.AsyncClient() as client:
        resp = await client.post(
            "http://localhost:8000/check",
            json={
                "tool_id": tool_name,
                "action": "invoke",
                "args": tool_args,
                "run_id": session_id
            }
        )
        result = resp.json()
        if not result["allowed"]:
            raise SecurityError(f"Blocked by ControlPlane: {result['reason']}")

🔌 3. Chrome Extension Network Shield

The browser extension intercepts user prompt forms and network fetch calls on supported AI platforms (ChatGPT, Claude, Gemini, Kimi, DeepSeek) to dynamically mask credentials and block prompt injections.

Setup Steps:

  1. Open Chrome and navigate to chrome://extensions/.
  2. Toggle **Developer mode** to ON in the top-right corner.
  3. Click **Load unpacked** in the top-left corner.
  4. Select the directory: C:\\ControlPlane\\frontend\\extension.
  5. Open the extension toolbar popup, click **⚡ Auto-Enroll Extension** to connect to localhost:8000.
  6. The status badge will switch to **CONNECTED** 🟢 and start safeguarding your prompts!

🔐 4. Cryptographic Hash Chain Telemetry

Every guardrail check logs telemetry. To ensure that attackers or malicious operators cannot wipe evidence from the database, we run a SHA-256 hash chaining system: 

Current Hash = SHA-256(Previous Hash + Interception Data Payload)

If any historical record is deleted or modified, the next record's computed hash chain mismatches, instantly highlighting the log tampering event on the dashboard security scorecard.
